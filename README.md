# 黑白极简 · 商品店铺模板（本地编辑 → 部署 GitHub Pages）

黑白极简风格购物网站。**完全纯静态、无后端**，最终产物是一堆可以直接丢上 GitHub Pages 的静态文件。商品点击看简介，「立即购买」跳转 Facebook Marketplace。

> 核心思路：本地用一个 WebUI 编辑商品，改完自动覆盖仓库里的 `index.html`，然后把整个文件夹推送到 GitHub Pages 即是线上发布。编辑器本身不部署。

## 目录结构

```
.
├── index.html      # 生成后的商品首页(会自动被工具覆盖, 这就是 GitHub Pages 的入口)
├── style.css       # 黑白极简样式
├── server.py       # 仅本机编辑用: 打开 WebUI 改商品, 保存即覆盖 index.html
├── run.sh          # 一键启动本地编辑器
├── products.json   # 商品数据(工具自动维护)
└── images/         # 上传的商品图片(自动生成)
```

## 怎么用（两步）

### 第 1 步：本地编辑商品

```bash
bash run.sh
```

浏览器打开 `http://127.0.0.1:8000/admin`（本地无密码）。

- 新增 / 编辑商品：名称、价格、分类、简介、购买链接（填你的 FB Marketplace 物品页）
- 上传商品图片 → 自动存进 `images/`
- 删除 / ↑↓ 排序
- **每次「保存」都会自动覆盖仓库根目录的 `index.html`**

可随时在 `http://127.0.0.1:8000/` 预览即将发布的效果。

### 第 2 步：推到 GitHub Pages

改完停掉工具，把整个文件夹提交并推送到 GitHub（`git commit / push`），在仓库的 GitHub Pages 设置里把发布源指向仓库根目录即可。线上展示的就是你刚才改好的 `index.html` + `style.css` + `images/`。

> 发布的是纯静态文件；`server.py` / `run.sh` 只是你本地的编辑工具，不需要也不会被发布使用。

## 要点

- **空商品状态**：商品列表为空时，首页自动显示「暂时没有在售商品」的空店提示，不留演示数据，也不暴露任何管理入口。
- **公开页面干净**：生成的首页不含任何 "admin / 管理" 链接（管理入口只在本地工具里）。
- **商品用图片**：没传图的商品在首页显示黑块占位 ◼，传了图就显示实拍图。
- 顺带把你的「购买链接」改成 FB Marketplace 物品页，全站跳转都走它。

## 网站设置（暗色 + 自定义）

后台点工具栏的「⚙ 网站设置」可改，无需碰代码：

- 站点标题、Logo 文字、顶部副标题（tagline）、页脚两段文案（**留空即不显示**，可随时填回）
- 默认配色主题：跟随系统 / 浅色 / 深色
- 明暗两套配色（背景 / 文字 / 次要文字）用取色器改
- 首页右上角有**明暗切换按钮 ◐**（记忆选择，默认跟随系统）

改动保存后自动覆盖 `index.html`。也可以在 `server.py` 顶部的 `SITE` 配置里直接改作为默认值。

## 本地依赖

只要本机装了 Python 3（无需任何第三方库）。
